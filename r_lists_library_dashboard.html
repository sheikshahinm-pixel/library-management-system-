1 · What is a list?

      
    
        
  • A list holds items of different types together: text, numbers, TRUE/FALSE, even vectors and other lists.
    • 
        
  • info <- list(name = "City Library", open = TRUE)
    • 
        
  • A vector must hold one type only; a list does not.
    • 
      

    
2 · Accessing items

      
    
        
  • info$name – by name.
    • 
        
  • info[["city"]] – by name with double brackets.
    • 
        
  • books[[2]] – by position.
    • 
        
  • books[[1]]$title – item inside an item.
    • 
      

    
3 · Changing a list

      
    
        
  • Add: info$members <- 250
    • 
        
  • Change: info$city <- "Madurai"
    • 
        
  • Remove: info$open <- NULL
    • 
        
  • Append to a list of lists: books[[length(books) + 1]] <- list(...)
    • 
        
  • Try these with the Add and ✕ buttons on the dashboard.
    • 
      

    
4 · List of lists

      
    
        
  • books is a list where every item is itself a list (one book).
    • 
        
  • This is how R stores records without a data frame.
    • 
        
  • seq_along(books) gives 1, 2, 3 … to loop over.
    • 
      

    
5 · Working on every item

      
    
        
  • sapply(books, function(b) b$pages) – pull one field from every book into a vector.
    • 
        
  • Filter(function(b) b$available, books) – keep only matching books.
    • 
        
  • for (b in books) – loop over each item.
    • 
      

    
6 · Handy functions

      
    
        
  • length() – how many items.
    • 
        
  • names() – the item names.
    • 
        
  • str() – show the structure of a list (see the access practice box).
    • 
      

    
Ideas to extend the project

      
    
        
  • Add a borrower field and list who has which book.
    • 
        
  • Sort books by pages: books[order(sapply(books, function(b) b$pages))]
    • 
        
  • Turn the list into a table: do.call(rbind, lapply(books, as.data.frame))
    • 
      

  







  

    
Run the project in R

    
    
      
  1. Install R (and optionally RStudio) from cran.r-project.org.
    2. 
      
  2. Open the R Code tab and click Download library_catalog.R (or copy the code into a new script in RStudio).
    3. 
      
  3. In RStudio press Source, or from a terminal run: Rscript library_catalog.R
    4. 
      
  4. Edit the books list in the script — add or remove a book — and run again.
    5. 
      
  5. In the R console, type str(books[[1]]) after sourcing the script to see one book's structure.
    6. 
    

    
Note: this dashboard re-implements the same logic in JavaScript so it can run live in a browser. The R script is the actual project; the dashboard is its visual front end.
